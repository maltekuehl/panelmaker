# Public API

PanelMaker provides a read-only public REST API for programmatic access to all community data. No API key is required for public endpoints.

**Base URL:** `https://panelmaker.ai/api`

All responses are JSON. A list endpoint returns its rows under the resource name, plus a cursor when more rows are
available:

```json
{
  "proteins": [...],
  "nextCursor": "prot_01abc"
}
```

## Pagination

List endpoints use cursor-based pagination. Pass `cursor=<nextCursor>` from the previous response to fetch the next
page. The default page size is 20; the maximum is 100.

```
GET /api/proteins?limit=50&cursor=prot_01abc
```

When `nextCursor` is absent, you have reached the last page.

## Proteins

### List proteins

```
GET /api/proteins
```

**Query parameters:**

| Parameter | Type    | Description                                     |
| --------- | ------- | ----------------------------------------------- |
| `q`       | string  | Text search across gene symbol and protein name |
| `limit`   | integer | Results per page (default 20, max 100)          |
| `cursor`  | string  | Pagination cursor from previous response        |

**Example:**

```bash
curl "https://panelmaker.ai/api/proteins?q=CD3&limit=10"
```

**Response:**

```json
{
  "proteins": [
    {
      "id": "P07766",
      "label": "CD3 epsilon",
      "geneSymbol": "CD3E",
      "ensemblGeneId": "ENSG00000198851"
    }
  ]
}
```

When a query matches nothing locally, the endpoint falls back to UniProt and adds `"source": "uniprot"`.

### Get a single protein

```
GET /api/proteins/[id]
```

Returns the full protein record including linked antibodies and validation report counts.

## Antibodies

### List antibodies

```
GET /api/antibodies
```

**Query parameters:**

| Parameter | Type    | Description                                                 |
| --------- | ------- | ----------------------------------------------------------- |
| `q`       | string  | Text search across clone name, vendor, catalog number, RRID |
| `limit`   | integer | Results per page (default 20, max 100)                      |
| `cursor`  | string  | Pagination cursor                                           |

**Example:**

```bash
curl "https://panelmaker.ai/api/antibodies?q=SP6"
```

### Get a single antibody

```
GET /api/antibodies/[id]
```

## Validation Reports

### List reports

```
GET /api/reports
```

**Query parameters:**

| Parameter  | Type    | Description                                                   |
| ---------- | ------- | ------------------------------------------------------------- |
| `q`        | string  | Text search across notes and antibody fields                  |
| `species`  | string  | Species ontology id, e.g. `NCBI:txid9606` for human           |
| `tissue`   | string  | Tissue ontology id, e.g. `UBERON:0002106`                     |
| `method`   | string  | `PATHOPLEX`, `CODEX`, `CYCIF`, `IMC`, `MIBI`, `IBEX`, `OTHER` |
| `fixation` | string  | `FFPE`, `FRESH_FROZEN`, `PFA`, `ACETONE`, `METHANOL`, `OTHER` |
| `limit`    | integer | Results per page (default 20, max 100)                        |
| `cursor`   | string  | Pagination cursor                                             |

**Example:**

```bash
curl "https://panelmaker.ai/api/reports?species=NCBI:txid9606&method=CODEX&fixation=FFPE"
```

**Response:**

```json
{
  "reports": [
    {
      "id": "rep_01xyz",
      "experimentId": "exp_01abc",
      "antibodyId": "ab_01abc",
      "status": "PUBLISHED",
      "works": true,
      "signalQuality": "EXCELLENT",
      "dilution": "1:200",
      "fluorophore": "Alexa Fluor 488",
      "imageUrls": ["/uploads/6f1c....webp"]
    }
  ],
  "nextCursor": "rep_01xyz"
}
```

### Get a single report

```
GET /api/reports/[id]
```

## Cell Types

### List cell types

```
GET /api/cell-types
```

**Query parameters:**

| Parameter | Type    | Description                            |
| --------- | ------- | -------------------------------------- |
| `q`       | string  | Text search by cell type name or CL ID |
| `limit`   | integer | Results per page (default 20, max 100) |
| `cursor`  | string  | Pagination cursor                      |

### Get a single cell type

```
GET /api/cell-types/[id]
```

Returns the cell type record with associated known markers and validation report counts.

---

## Panels

### List public panels

```
GET /api/panels/public
```

Returns panels that have been marked as public by their creators. `GET /api/panels` is a different, authenticated
endpoint that lists your own panels.

**Query parameters:**

| Parameter | Type    | Description                            |
| --------- | ------- | -------------------------------------- |
| `limit`   | integer | Results per page (default 20, max 100) |
| `cursor`  | string  | Pagination cursor                      |

## Error responses

| Status | Meaning                                             |
| ------ | --------------------------------------------------- |
| `400`  | Bad request: invalid query parameters               |
| `404`  | Resource not found                                  |
| `429`  | Rate limit exceeded: check the `Retry-After` header |
| `500`  | Internal server error                               |

Error responses follow the shape (`details` is present for validation errors):

```json
{
  "error": "Resource not found"
}
```
