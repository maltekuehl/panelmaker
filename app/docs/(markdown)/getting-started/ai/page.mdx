# AI Assistant

The PanelMaker AI assistant is available via the chat icon in the bottom-right corner of any page. It is powered by a large language model with direct access to the PanelMaker database, so it can give answers grounded in real community data rather than generic training knowledge.

## What the assistant can do

The assistant has access to a set of built-in tools that query the PanelMaker database in real time:

| Tool                 | What it does                                                                |
| -------------------- | --------------------------------------------------------------------------- |
| `searchMarkers`      | Search the protein and antibody database by name, gene symbol, or RRID      |
| `getMarkerDetails`   | Retrieve full details for a specific marker including validation reports    |
| `searchCellTypes`    | Look up cell types and their known marker sets using the Cell Ontology      |
| `suggestPanel`       | Recommend a starter panel for a given tissue and imaging method             |
| `checkCompatibility` | Check a set of antibodies for fluorophore overlap or host species conflicts |

The assistant decides which tools to call based on your question. You do not need to invoke tools explicitly.

## Example prompts

**Finding markers for a cell type:**

> "What are good markers for regulatory T cells in human FFPE tissue?"

**Checking antibody compatibility:**

> "I want to use anti-CD3 (SP6 clone) and anti-CD8 (C8/144B clone) in the same cycle. Are there any compatibility issues?"

**Getting panel suggestions:**

> "Suggest a 10-marker CODEX panel for human tonsil covering major immune cell types."

**Looking up validation data:**

> "Has the Abcam anti-FOXP3 antibody (ab20034) been validated for IMC on mouse spleen?"

**Understanding a protocol:**

> "What is the difference between IBEX and CyCIF, and which is better for archival FFPE tissue?"

## Limitations

- The assistant can only retrieve data that is in the PanelMaker database. For antibodies or markers not yet submitted to the community, it will say so and suggest alternatives.
- Panel suggestions are starting points based on community data. Always review suggestions against your own experimental constraints before ordering reagents.
- The assistant cannot place orders, access external lab systems, or retrieve paywalled publications.
- Conversations are saved to your account, so you can pick one up again from the chat sidebar.

## API keys and models

The assistant always runs on an API key that someone configured for Google Gemini, OpenAI, or Anthropic. There is no free shared key. For each provider, the first key available in this order is used:

1. **Your own key**, added under [Settings](/settings#ai-keys). It is only used for your own conversations.
2. **Your lab's key**, added by a lab admin or owner in the lab's settings. It is shared with every member of that lab. If you belong to several labs, pick which lab's keys a conversation uses from the model menu in the chat.
3. **The instance key**, configured by the operator of this instance.

The model menu in the chat groups models by provider and shows which key each one would use. Models without any key are shown as unavailable, and the chat explains how to add one. Keys are encrypted at rest, checked with the provider when you save them, and only their last 4 characters are ever shown again.

## Rate limiting

Chats that run on your own key or your lab's key are not limited by PanelMaker; your provider's own limits apply. Chats on the instance key may have a daily per-user limit set by the operator. When you reach it, the assistant tells you, and you can continue by adding your own key.
