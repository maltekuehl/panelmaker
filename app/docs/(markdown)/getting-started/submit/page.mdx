# Submit Validation Reports

Validation reports are the backbone of PanelMaker. They record how a specific antibody performed under defined experimental conditions, helping other researchers make informed reagent choices.

To submit a report, navigate to [/submit](/submit). You must be signed in.

## What counts as a validation report?

A validation report documents a single antibody tested in a single experimental context. The key fields are:

| Field                 | Description                                                                        | Required    |
| --------------------- | ---------------------------------------------------------------------------------- | ----------- |
| Antibody              | The specific antibody (clone + vendor)                                             | Yes         |
| Verdict               | Recommended, usable with caveats, or not recommended                               | Recommended |
| Imaging method        | EFO spatial proteomics assays (t-CyCIF, IBEX, PhenoCycler, IMC, MIBI-TOF and more) | Yes         |
| Species               | The organism the tissue came from                                                  | Yes         |
| Tissue                | The tissue type imaged                                                             | Yes         |
| Preservation          | FFPE, fresh frozen, fixed frozen, fresh, or other                                  | Yes         |
| Fixative              | The fixative chemistry, as a ChEBI term                                            | Recommended |
| Working concentration | Dilution, and optionally the concentration in µg/mL                                | Recommended |
| Cell type             | Positive control cell type expected to stain                                       | Recommended |
| Notes                 | Free-text observations, staining artifacts, optimisation tips                      | Optional    |

## Verdict, issues and specificity controls

Each antibody gets a verdict for this experiment: **recommended**, **usable with caveats**, or **not recommended**. The verdict holds for the tissue, preservation and method of this run only. The same antibody can be recommended on frozen tissue and not recommended on FFPE, and both reports are useful.

**Issues** say what limited the stain, for example weak signal, high background, off-target staining, signal lost during cycling or retrieval, autofluorescence in the channel, bleed-through, or a neighbouring antibody blocking the epitope. Pick as many as apply. They explain a "with caveats" or "not recommended" verdict, and they help others place the marker in a cyclic panel.

**Specificity controls** record how you know the stain is specific. For each control you ran, mark whether it supports the staining, contradicts it, or was inconclusive:

- Knockout or knockdown control
- Independent antibody against a different epitope
- Agreement with RNA (in situ hybridization or single cell data)
- Agreement with single-marker IHC or IF
- Expected cell types and subcellular compartment
- Positive and negative control tissue
- Secondary-only or no-primary control
- Isotype control

Leave the controls you did not run empty. PanelMaker shows the evidence as you recorded it and does not turn it into a specificity score.

## Ontology-backed fields

Species, tissue, and cell type fields use controlled vocabularies to ensure consistency across submissions:

- **Species**: NCBI Taxonomy (e.g., _Homo sapiens_ = `9606`, _Mus musculus_ = `10090`)
- **Tissue**: UBERON anatomical ontology (e.g., `UBERON:0002106` for spleen)
- **Cell type**: Cell Ontology (e.g., `CL:0000236` for B cell)

Start typing in any of these fields and the autocomplete will query the relevant ontology in real time. Select the term from the dropdown to store both the display name and the ontology ID. This allows downstream filtering and cross-experiment comparison.

## Imaging methods

The imaging method field searches the spatial proteomics branch of the [Experimental Factor Ontology](https://www.ebi.ac.uk/ols4/ontologies/efo) (EFO), the same way species and tissue search their ontologies. Any assay EFO lists there can be picked, and new EFO terms show up without a PanelMaker update.

Methods EFO has no term for yet, such as PathoPlex, are listed by name and filed under their closest EFO term (for PathoPlex, multiplex immunofluorescence imaging assay).

Every antibody can record a fluorophore, a metal tag and a cycle number, whatever the method.

## Rate limiting

To protect data quality, report submission is rate-limited to **50 reports per 24-hour period** per account. If you have a larger dataset to submit, please contact your instance administrator.

## After submission

Submitted reports enter a review queue. Reviewers check that:

- The antibody exists in the database (or flag it for addition)
- The ontology terms are correctly matched
- The experimental context is plausible

Once reviewed, the report becomes publicly visible on the relevant antibody and marker pages. You will receive a notification when your report is approved or if clarification is needed.

## Tips for high-quality reports

- Include both **positive** and **negative** results. Failed validations are just as valuable to the community
- Attach up to five images (fields of view) per antibody. If one image shows several of the run's antibodies, upload it once and tick the others under "Also shows" instead of uploading it again
- For each antibody, you can give its colour in the image. Leave it empty if you do not know it: the colour is never guessed from the fluorophore
- List counterstains such as DAPI or phalloidin under "Counterstains in this image", with their role (nuclear or structural) and, optionally, fluorophore and colour
- If you optimised a protocol, describe the key changes in the notes field
- Reference a publication or preprint if the data is from a published experiment
