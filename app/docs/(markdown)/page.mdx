# PanelMaker Introduction

Learn all about **PanelMaker in less than 5 minutes**.

## What is PanelMaker?

PanelMaker is a community-driven platform for designing, validating, and sharing antibody panels for spatial proteomics experiments. It helps researchers working with multiplexed imaging technologies (CODEX, IBEX, CyCIF, IMC, MIBI, and others) build optimal marker panels.

| Feature                   | Description                                                                |
| ------------------------- | -------------------------------------------------------------------------- |
| Browse validated markers  | Search proteins and antibodies with community-submitted validation reports |
| Design antibody panels    | Build multi-cycle panels with fluorophore and metal tag assignments        |
| Submit validation reports | Share experimental results including species, fixation, and imaging method |
| AI-assisted design        | Get recommendations for panel composition and compatibility checks         |
| Public API                | Programmatic access to all public data                                     |

## Key Concepts

- **Marker**: A protein target identified by antibody staining in tissue sections
- **Antibody Panel**: A collection of antibodies organized into imaging cycles
- **Cycle**: A single round of staining and imaging in a multiplexed experiment
- **Validation Report**: Community-submitted data about antibody performance under specific conditions

## Getting Started

1. **Browse** the marker database at [/browse](/browse) to find validated antibodies
2. **Design panels** at [/panel](/panel) using the visual panel designer
3. **Submit reports** at [/submit](/submit) to share your experimental validations
4. **Use the AI assistant** to get recommendations for panel design
