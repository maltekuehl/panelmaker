# About PanelMaker

## What is PanelMaker?

PanelMaker is an open-source platform for designing, validating, and sharing antibody panels for spatial proteomics experiments. It helps researchers working with multiplexed imaging technologies (CODEX, IBEX, CyCIF, IMC, MIBI, and others) build optimal marker panels, backed by a marker and antibody database with experimental validation reports.

The project is released under the Apache-2.0 license and developed in the open on [GitHub](https://github.com/complextissue/panelmaker).

## This instance

You are using a self-hosted instance of PanelMaker, deployed and operated by your institution. Each instance has its own users, labs, and data: reports, panels, and inventory submitted here are shared within this instance and are not sent to any other deployment or to a central PanelMaker service. The PanelMaker software itself is a shared, upstream open-source project that any research group can deploy for its own institution.

## Project status

PanelMaker is under active development. Already available:

- **Marker and antibody database** with experimental validation reports
- **Panel designer** with fluorophore overlap detection and host species cross-reactivity checks
- **Labs**: shared panel libraries and antibody inventory for a research group
- **Image uploads** attached to reports (PNG, JPEG, WebP, TIFF up to 80 MB)
- **CSV and JSON export** of panels
- **AI assistant** with direct, tool-based access to the instance database
- **Public read-only API** for proteins, antibodies, cell types, reports, and public panels

Development happens in the open. See the [issue tracker](https://github.com/complextissue/panelmaker/issues) on GitHub for planned work, and open an issue or discussion to suggest a feature.
