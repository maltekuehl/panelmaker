# PanelMaker Introduction

Learn all about **PanelMaker in less than 5 minutes**.

## What is PanelMaker?

PanelMaker is an open-source platform for designing, validating, and sharing antibody panels for spatial proteomics experiments. It helps researchers working with multiplexed imaging technologies (CODEX, IBEX, CyCIF, IMC, MIBI, and others) build optimal marker panels. This site is one self-hosted instance of PanelMaker, run by your institution. See [About](/docs/about) for details on the project and how to run your own instance.

| Feature                   | Description                                                                             |
| ------------------------- | --------------------------------------------------------------------------------------- |
| Browse validated markers  | Search proteins and antibodies with submitted validation reports                        |
| Design antibody panels    | Build multi-cycle panels with fluorophore and metal tag assignments                     |
| Submit validation reports | Share experimental results including species, preservation, fixative and imaging method |
| Labs                      | Shared panel libraries and antibody inventory for a research group                      |
| AI-assisted design        | Get recommendations for panel composition and compatibility checks                      |
| Public API                | Programmatic access to all public data on this instance                                 |

## Key Concepts

- **Marker**: A protein target identified by antibody staining in tissue sections
- **Antibody Panel**: A collection of antibodies organized into imaging cycles
- **Cycle**: A single round of staining and imaging in a multiplexed experiment
- **Validation Report**: Submitted data about antibody performance under specific conditions
- **Lab**: A research group with shared panels and antibody inventory within this instance

## Getting Started

1. **Browse** the marker database at [/browse](/browse) to find validated antibodies
2. **Design panels** at [/panel](/panel) using the visual panel designer
3. **Submit reports** at [/submit](/submit) to share your experimental validations
4. **Use the AI assistant** to get recommendations for panel design
